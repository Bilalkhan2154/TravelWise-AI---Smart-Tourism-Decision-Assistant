# 🌍 TravelWise AI – Smart Tourism Decision Assistant

TravelWise AI is an intelligent tourism recommendation system that helps travelers make informed travel decisions by combining curated destination information with real-time weather and climate data. The application provides personalized travel recommendations based on user preferences, budget, season, and interests, making trip planning simple, efficient, and reliable.

---

## 📌 Problem Statement

Planning a trip often requires travelers to search multiple websites for information about destinations, weather, travel seasons, budgets, and attractions. This process is time-consuming and can result in incomplete or inaccurate travel decisions.

TravelWise AI solves this problem by bringing all essential travel information into one platform and providing smart, personalized destination recommendations.

---

## 🚀 Features

- 🌤️ Live Weather Forecast (Open-Meteo API)
- 📍 Smart Destination Recommendations
- 🗺️ Coverage of all Indian States & Union Territories
- 💰 Budget-Based Travel Suggestions
- 📅 Best Time to Visit Recommendations
- 🏛️ Cultural & Heritage Information
- 👥 Crowd Level Estimation
- 🛡️ Safety Tips for Travelers
- 📖 Wikipedia Destination Summaries
- 🌍 Fallback Support when Internet is Unavailable

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/TravelWise-AI.git
```

### Navigate into the project

```bash
cd TravelWise-AI
```

### Install dependencies

```bash
pip install -r requirements.txt
```

or

```bash
pip install flask requests
```

### Run the application

```bash
python Tourism_app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

---

## 💡 How It Works

1. User enters travel preferences.
2. The application analyzes:
   - Budget
   - Season
   - Weather
   - Destination popularity
   - Cultural significance
3. Live weather and climate information are fetched.
4. AI-based scoring recommends the most suitable destinations.
5. Users receive detailed travel insights and recommendations.
