🇮🇳 TravelWise AI – Smart Tourism Decision Assistant

TravelWise AI is an intelligent tourism recommendation platform built using **Python** and **Streamlit** that helps travelers make informed travel decisions across India. The application combines **live weather data**, **AI-powered crowd estimation**, **travel scoring**, and **destination recommendations** to provide a smarter and more personalized travel planning experience.

Unlike traditional travel guides, TravelWise AI analyzes real-time conditions and seasonal trends to recommend the best destinations while helping users avoid overcrowded locations and unfavorable weather.

---

## ✨ Features

- 🌍 Covers destinations from all Indian States and Union Territories
- 🌦️ Live weather updates using Open-Meteo API
- 🤖 AI-based crowd estimation system
- ⭐ Smart Travel Score based on weather, season, and crowd levels
- 📍 Intelligent destination search with fuzzy matching
- 📖 Live destination summaries from Wikipedia
- 📅 Best time to visit recommendations
- 📊 Interactive charts and analytics using Plotly
- 🎨 Modern responsive Streamlit interface with custom UI
- 🚀 No API key required (Uses free public APIs)

---

## 🧠 How It Works

1. Users search for any destination in India.
2. The application retrieves the destination information.
3. Live weather data is fetched from Open-Meteo APIs.
4. An AI-inspired algorithm estimates expected crowd levels based on:
   - Season
   - Weather conditions
   - Popularity of the destination
   - Weekends and holidays
5. A Travel Score is generated to help users decide whether it is a good time to visit.
6. The application displays recommendations, weather forecasts, crowd analysis, and destination insights in an interactive dashboard.
